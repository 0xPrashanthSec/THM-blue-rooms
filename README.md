# TryHackMe Cybersecurity Learning Roadmap

A structured collection of TryHackMe rooms covering Linux, Windows, networking, scripting, web security, malware analysis, privilege escalation, Active Directory, packet analysis, and other practical security topics.

> **Use only in authorized labs and systems where you have explicit permission.**

## How to use this roadmap

- Start with **Linux Fundamentals**, **Windows Fundamentals**, and **Networking**.
- Continue with **Basics Rooms** and **Scripting**.
- Move into **Web**, **Windows**, and **Privilege Escalation**.
- Study **Active Directory**, **Malware Analysis**, and **PCAP Analysis** after building the foundations.
- Keep notes for every room: commands used, findings, mistakes, remediation, and lessons learned.
- Complete rooms in a legal lab environment and document your progress.

## Suggested learning order

1. Linux Fundamentals
2. Windows Fundamentals
3. Networking
4. Basics Rooms
5. Web Security
6. Windows Security
7. Privilege Escalation
8. Active Directory
9. Malware Analysis

## Progress tracker

Use the following status labels beside each room:

- `[ ]` Not started
- `[-]` In progress
- `[x]` Completed
- `[R]` Revisit

For each completed room, record:

- Completion date
- Important commands and tools
- Attack path or investigation method
- Detection and remediation ideas
- Links to personal notes or write-ups

## Repository purpose

This repository is intended to organize hands-on cybersecurity learning and build a reusable knowledge base. The goal is not only to complete rooms, but also to understand the underlying behavior, recognize relevant evidence, and connect offensive techniques to practical detection and defense.

## Disclaimer

The material referenced here is for education and authorized security testing only. Do not test techniques against systems, accounts, networks, or applications without explicit permission.
